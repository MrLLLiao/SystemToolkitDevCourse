===== 说明 =====
proselint 是子命令式工具（proselint check <file>），无 --version 参数；空文件参数时读 stdin 卡死，Action 内须加空守卫
===== proselint check README.md =====
PASS（无文体问题）

===== 自定义 Action 配置 =====
# 自定义复合 Action：对传入的 markdown 文件运行 proselint 并报告文体违规。
# 用法：
#   - uses: ./.github/actions/proselint-check
#     with:
#       files: README.md docs/foo.md
name: 'Proselint Markdown Check'
description: 'Run proselint on given markdown files and report style lapses'

inputs:
  files:
    description: 'Space-separated markdown file paths to check'
    required: true

runs:
  using: 'composite'
  steps:
    - name: Install proselint
      shell: bash
      run: python -m pip install --quiet proselint
    - name: Run proselint on markdown files
      shell: bash
      run: |
        FILES="${{ inputs.files }}"
        if [ -z "$FILES" ]; then
          echo "无 markdown 变更，跳过"
          exit 0
        fi
        proselint check $FILES

===== md-lint 工作流（增量检查变更 .md） =====
# md-lint：.md 变更时用自定义 proselint Action 检查文体。
# 增量策略：只检查本次变更的 .md（与 ci.yml 的格式/lint 一致，不回溯存量）。
name: md-lint

on:
  push:
    branches: [master, main]
  pull_request:

jobs:
  prose:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - name: Compute changed markdown files
        id: changed
        run: |
          if [ "${{ github.event_name }}" = "pull_request" ]; then
            BASE="${{ github.event.pull_request.base.sha }}"
          else
            BASE="${{ github.event.before }}"
          fi
          if [ -z "$BASE" ] || [ "$BASE" = "0000000000000000000000000000000000000000" ]; then
            echo "files=" >> "$GITHUB_OUTPUT"
            exit 0
          fi
          FILES=$(git diff --name-only "$BASE"...HEAD -- '*.md' || true)
          echo "files=$FILES" >> "$GITHUB_OUTPUT"
      - uses: ./.github/actions/proselint-check
        with:
          files: ${{ steps.changed.outputs.files }}
