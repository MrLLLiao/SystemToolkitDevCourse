# 练习5：正则查找替换项目符号

## 练习内容
把 Markdown 中 `- ` 项目符号统一替换为 `* `。

## 实现
锚定行首、限定"单个连字符+空格"，避免误伤 `---` 分隔线或嵌套列表：

```bash
perl -pi -e 's/^\- /\* /' README.md
```

## 验证结果
替换前后对比见 output.txt（before.md → after.md）。替换后 `grep -nE '^\- '` 无残留，`---` 分隔线不受影响。
