MudGame

系统开发工具基础（Missing Semester）课程练习项目 —— 命令行采矿游戏。

构建与测试

  • make build —— CMake 配置并构建
  • make test —— 运行全部单元测试（21 个用例）
  • make coverage —— 生成覆盖率报告
  • make clean —— 清理构建产物

质量门禁

  • clang-format 格式检查（增量：只检查变更文件）
  • cppcheck 静态分析（生产代码）
  • pre-commit：格式 + lint + 构建 + 测试，任一失败拒绝提交
  • GitHub Actions CI：构建、测试、格式/lint/shellcheck
