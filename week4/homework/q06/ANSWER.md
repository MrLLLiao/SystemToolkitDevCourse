# 练习6：从 JSON 捕获 name 与命令行解析器

## 练习内容
用正则从 JSON 抓 name 字段（处理贪婪量词与转义引号），再写几行代码的命令行解析器。

## 正则的三种写法对比（PCRE，grep 的 ERE 连懒惰量词都不支持）
输入样例：`{"name": "say \"hi\"", "note": "含转义引号"}`

| 正则 | 结果 |
|------|------|
| `"name": "(.*)"` | 贪婪：跨字段捕获到行尾最后一个引号，误捕获 |
| `"name": "(.*?)"` | 懒惰：在转义引号处提前收口，少捕获 |
| `"name": "((?:[^"\\]|\\.)*)"` | 转义感知：正确，但已难以维护 |

## 正确的做法
用真正的解析器：jq 一行、或几行代码的 python（json 模块递归提取）。`json_extract.py` 是通用 CLI：传入 JSON 文件与键名，递归提取所有匹配值。

## 验证结果
对真实数据（ore.json 5 种矿石）提取 name，正确输出：黯铁矿、星纹银、赤耀金、雷鸣晶、世界之核。
