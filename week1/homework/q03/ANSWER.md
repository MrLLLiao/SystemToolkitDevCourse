# 练习3: 单引号、双引号和 ANSI-C 引号

## 三种引号的区别

| 引号类型 | 语法 | 行为 |
|----------|------|------|
| 单引号 `'...'` | `'literal'` | 完全字面量，所有字符按原样输出，不做变量展开、命令替换或转义解释 |
| 双引号 `"..."` | `"value: $var"` | 允许变量展开（`$var`）、命令替换（`$(cmd)`）和转义（`\$`, `\``, `\"`, `\\`），但 `!` 在交互Shell中可能触发历史扩展 |
| ANSI-C 引号 `$'...'` | `$'line1\nline2'` | 解释反斜杠转义序列（`\n`换行, `\t`制表符, `\uXXXX`Unicode等），其余按字面量 |

## 输出含字面量 $ 、 ! 和换行符的字符串
最安全的方式是使用单引号，因为单引号内所有字符都是字面量：
```bash
echo 'Cost: $100! Discount: 50%
Buy now!'
```
单引号内可以直接换行，换行符会被保留。

也可以用 ANSI-C 引号显式写 `\n`：
```bash
echo $'Price: $9.99!\nLimited offer!'
```

## 注意
- 双引号中 `$` 会触发变量展开，要输出字面量 `$` 需用 `\$` 或改用单引号
- 交互 Shell 中 `!` 可能触发历史扩展，脚本中通常无此问题
- 单引号内不能再包含单引号（即使转义也不行）
