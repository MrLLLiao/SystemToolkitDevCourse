# 练习9: 递归找出最近修改的文件 / 按修改时间列出所有文件

## 练习要求
（进阶）写一个命令或脚本，递归找出某个目录中最近修改过的文件。更一般地，能不能按"最近修改时间"列出所有文件？

## 核心思路
`find -printf` 可以直接输出文件修改时间与路径，配合 `sort` 即可按时间排序：

| 格式符 | 含义 |
|--------|------|
| `%T@` | 修改时间的 **epoch 秒数**（带小数），数值可排序 |
| `%T+` | 人类可读时间（`2026-08-28+12:00:00.0000000000`） |
| `%p`  | 文件路径 |

## 目标命令

**1) 最近修改的一个文件**
```bash
find . -type f -printf '%T@ %p\n' | sort -rn | head -1
```

**2) 按修改时间列出所有文件（新 → 旧）**
```bash
find . -type f -printf '%T@ %T+ %p\n' | sort -rn
```

## 关键点
- `-printf` 是 GNU find（Linux）的特性；`sort -rn` 按 epoch 秒数数值**降序**排列，`-r` 逆序、`-n` 数值比较。
- 递归天然由 `find` 完成（`find .` 会遍历所有子目录）。
- 备用写法（不依赖 -printf 的自定义格式）：
  ```bash
  find . -type f -exec ls -lt {} +
  ```

## 实测结果
构造 5 个不同修改时间的文件后：
- 最近修改的文件是 `./root.log`（2026-08-28）；
- `sort -rn | head -3` 给出最近的前 3 个；
- `%T+` 版本把全部文件按时间从新到旧完整列出（见 output.txt）。
