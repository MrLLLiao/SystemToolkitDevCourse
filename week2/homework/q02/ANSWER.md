# 练习2: 综合 ls 命令

## 练习要求
阅读 ls 的 man page，写一个 ls 命令，让它：
1. 包含所有文件（包括隐藏文件）
2. 文件大小以易读格式显示（例如 `454M`，而不是 `454279954`）
3. 按最近修改时间排序
4. 输出带颜色

## 目标命令

```bash
ls -lah -t --color=always
```

| 选项 | 含义 | 对应要求 |
|------|------|----------|
| `-l` | 长格式（显示权限、大小、时间等） | 使输出包含示例中的完整信息 |
| `-a` | `--all`，包含所有文件，包括以 `.` 开头的隐藏文件 | 要求 1 |
| `-h` | `--human-readable`，把字节数换算成 1.1M、454M 等易读单位 | 要求 2 |
| `-t` | `--sort=time`，按修改时间（newest first）排序 | 要求 3 |
| `--color=always` | 强制输出 ANSI 彩色（按文件类型着色：目录、可执行、链接等） | 要求 4 |

## 实验输出要点
- 普通 `ls -l`：看不到 `.hidden`，`foo` 大小显示为 5242880（字节）。
- 加了 `-ah` 后：出现 `.hidden`，大小显示为 `5.0M`、`2.0M` 等易读单位。
- 加了 `-t` 后：按修改时间从新到旧排列（`.hidden` 最新 → `foo` 最旧）。
- `--color=always` 会在管道/重定向时也写入 ANSI 转义码（如 `ESC[01;34m` 目录蓝色），用 `cat -v` 可以看到这些控制码；终端里则直接呈现为彩色。

## 备注
- 交互式终端通常用 `--color=auto`（仅在输出到终端时着色）；`--color=always` 用于强制着色（例如管道给 `less -R` 或抓取彩色输出）。
- `--time-style=long-iso` 可把时间显示为 `2026-01-14 09:53` 形式，更易读。
- man 参考：`man ls` 中 `-a, --all`、`-h, --human-readable`、`-t, --sort=time`、`--color[=WHEN]`。
