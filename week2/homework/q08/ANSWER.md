# 练习8: pidwait 函数

## 练习要求
写一个叫 `pidwait` 的 bash 函数，接收一个 pid，一直等待到该进程结束。应该用 `sleep` 避免空转浪费 CPU。

## 为什么用 kill -0
讲义补充了一个知识点：`kill` 成功时退出状态为 0，失败时非 0。其中：
- `kill -0 <pid>` **不会真的发送任何信号**；
- 进程存在 → 返回 0；
- 进程不存在（或无权访问）→ 返回非 0。

因此 `kill -0` 是"探测进程是否存在"的惯用手段，可以用在轮询条件里。

## 实现（pidwait.sh）
```bash
pidwait() {
    local pid="${1:?需要提供一个 pid}"
    while kill -0 "$pid" 2>/dev/null; do
        sleep 1          # 关键: 每轮 sleep, 避免空转烧 CPU
    done
    echo "pid $pid 已结束"
}
```

## 与 wait 的区别
- `wait` 只能等**当前 shell 的子进程**；跨会话启动的进程等不了。
- `pidwait` 通过 `kill -0` 探测任意可见进程，**不要求是子进程**，所以更适合等待"另一个会话里启动"的进程。

## 实测结果
- 对 `sleep 3` 的 pid 调用 `pidwait`，约 3 秒后返回（期间每 1 秒轮询一次），随后 `kill -0` 返回非 0 确认进程已结束。
- 对不存在的 pid（999999）调用，`kill -0` 立即失败、循环一次都不进入，立即返回。

## 改进方向
- `sleep 1` 粒度可按需调整（更快响应用 `sleep 0.1`，更省资源用更长时间）。
- 可加超时上限，防止目标进程永不退出导致无限等待。
