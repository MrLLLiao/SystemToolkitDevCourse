GitHub Pages 是怎么工作的

GitHub Pages 会把仓库中的静态文件（gh-pages 分支、/docs 目录或 Actions 构建产物）发布到 https://<user>.github.io/<repo>/， 无需自己购买服务器，适合个人主页、项目文档与作品集。
